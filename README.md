# Digital Eyes - AI Web App

A web-based AI application that transforms a device's camera into digital eyes 
for blind people, performing object and color recognition, obstacle detection, 
person recognition, and real-time interaction with the system.

##  Features
- Real-time detection of colors, obstacles, objects, and persons
- Interactive voice interface using TTS & STT, since blind users 
  cannot rely on a touchable interface
- Ability to switch between models based on the user's needs

##  Technologies Used
- **FrontEnd**: Flutter
- **BackEnd**: FastAPI
- **Object Detection**: Fine-tuned YOLO
- **Image Classification**: CNN from scratch
-  **Color Detection**: HSV (OpenCV)
- **Speech**: TTS & STT
